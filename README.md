# Todo List

A task management web application built as part of The Odin Project JavaScript curriculum.

## Live Demo

[Open Todo List](https://vimaya353.github.io/Project-Todo-list/)

## Features

- Create and manage projects.
- Add, edit, complete, and delete todos.
- Set due dates, priorities, descriptions, and notes.
- Filter todos by completion status and priority.
- Sort todos by due date, priority, or title.
- View task summaries and project completion progress.
- Save projects and todos using browser Local Storage.

## Technologies Used

- HTML
- CSS
- JavaScript
- Webpack
- Local Storage API

## Run Locally

1. Clone this repository.
2. Install dependencies with `npm install`.
3. Start the development server with `npm start`.
4. Open the local address shown in the terminal.

## Deployment

The project is published using GitHub Pages.
